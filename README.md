## 마지막 한 단계 — 사장님이 직접 해주셔야 해요

Vercel에 이 저장소를 연결해서 `https://songdo-triple-hr.vercel.app` 같은 고정 주소를 만들려고 했는데, GitHub이 "새로 만든 저장소에 Vercel이 접근하려면 비밀번호로 본인 확인"을 요구했습니다. 비밀번호는 제가 대신 입력할 수 없는 부분이라 여기서 멈췄어요.

**이렇게 해주세요 (2분):**
1. https://vercel.com/new 접속 (로그인은 이미 되어 있을 거예요)
2. Import Git Repository 목록 아래 "Adjust GitHub App Permissions" 클릭
3. GitHub 비밀번호로 본인 확인
4. `songdo-triple-hr` 저장소를 Vercel 접근 허용 목록에 추가
5. 다시 vercel.com/new 로 돌아와서 `songdo-triple-hr` 옆의 **Import** 클릭 → **Deploy** (설정 변경 없이 그대로 진행하면 됩니다, 빌드 설정 필요 없는 순수 HTML이에요)

이 단계만 끝나면 나온 주소를 사장님도, 트레이니 직원도, 나중에 송도 트리플 매장에서도 그대로 쓰시면 됩니다. 이 단계 다시 저한테 알려주시면 이어서 확인해드릴게요.

## 만약 Vercel 대신 다른 방법을 원하시면

- GitHub 저장소는 이미 준비되어 있어서 Netlify나 다른 정적 호스팅에 연결하는 것도 가능해요
- 급하게 지금 당장 눈으로 보고 싶으시면, 말씀해주시면 1시간짜리 임시 링크를 바로 만들어드릴 수 있어요 (테스트용, 정식 배포 아님)

## 사용 방법

- **사장님(관리자)**: 배포된 주소로 접속 → 우측 상단 "관리자 모드" 버튼 → 비밀번호 입력 후 직원 추가, 기록 수정, 휴무 지정 가능
- **직원(트레이니)**: 같은 주소로 접속 → "출퇴근 체크" 탭에서 본인 이름 카드를 눌러 출근/퇴근 버튼만 누르면 됩니다
- **실시간 공유**: Firebase 하나를 같이 보고 있기 때문에, 직원이 어디서(이 매장이든, 나중에 송도 트리플 매장이든) 체크하든 사장님 화면에 실시간으로 반영됩니다. 인터넷만 연결되어 있으면 매장이 달라도 상관없어요

## 관리자 비밀번호 변경 방법

`index.html` 파일 맨 위 `ADMIN_PASSWORD` 값(`'0000'`)을 원하는 값으로 바꾼 뒤 GitHub에 다시 업로드하면 됩니다. 필요하시면 제가 대신 바꿔드릴게요.

## 보안 관련 참고

지금 버전은 빠르게 쓰실 수 있도록 "1단계 보안"(Firestore 규칙상 누구나 읽기/쓰기 가능)으로 설정되어 있어요. POS 초기 파일럿 때와 같은 방침입니다. 나중에 직원이 늘어나거나 이 앱을 담당 직원에게 완전히 넘기실 때는, 로그인 기능을 추가하고 Firestore 보안 규칙을 강화하는 걸 권장드려요.
